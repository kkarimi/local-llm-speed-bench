How the ratings work

Each rating compares a configuration with the leader for the selected metric and prompt length. The leader scores 100. Twice the wait or half the throughput scores 50. Ratings describe speed. Coding accuracy and answer quality were outside these tests.

Each row gives the median across its recorded samples after one warm-up. Input speed uses engine timings when available. Output speed estimates decode from streamed output and completion-token counts. First output includes any streamed reasoning.
